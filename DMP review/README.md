# DMP Review

This folder contains the Group 3 review material for the WP6 review of Group 5.

Review target:
https://test.researchdata.tuwien.ac.at/records/v888d-r0r44

## Folder structure

- `report/` contains the LaTeX review report draft.
- `notes/` contains the A/B review notes.
- `evidence/dmp/` contains the Group 5 DMP record, DMP PDF, extracted DMP text, and maDMP JSON.
- `evidence/github/` contains the checked GitHub repository metadata files.
- `evidence/tuwrd/` contains TUWRD model and generated-output record snapshots.
- `evidence/zenodo/` contains Zenodo API metadata snapshots.
- `evidence/dbrepo/` contains the DBRepo page snapshot for the later C-side check.

## Current scope

- Owner A checks: GitHub repository, Zenodo/software publication, model deposit, generated-output deposit, and metadata consistency notes.
- Owner B checks: DMP record, final DMP PDF, maDMP JSON, FWF DMP completeness, and maDMP technical validity notes.

The remaining parts for the final max. 3-page review report are expected to be completed from the C and D checks: DBRepo/data description and metadata-standard artefacts.
